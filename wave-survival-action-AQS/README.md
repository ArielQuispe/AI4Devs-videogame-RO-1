# Wave Survival Action Game

## Overview
The Wave Survival Action Game is a client-side web game where players must survive waves of enemies while collecting buffs to enhance their abilities. The game is built using HTML, CSS (Bootstrap 5), and JavaScript, ensuring a smooth and engaging experience without the need for additional frameworks.

## Project Structure
```
wave-survival-action-game/
├── index.html          # Main entry point for the game
├── actions.js          # JavaScript code for game logic and interactions
├── style.css           # Custom styles complementing Bootstrap 5
├── assets/             # Directory for images and resources
│   ├── buffs.jpg       # Sprites for buffs
│   ├── characters.png  # Sprites for player characters
│   └── enemies.png     # Sprites for enemies
└── README.md           # Documentation for the project
```

## Setup Instructions
1. Clone the repository or download the project files.
2. Open `index.html` in a web browser to start the game.
3. Ensure that your browser allows local storage for saving game progress.

## Gameplay Mechanics
- Players can choose a character and start a new game or view high scores.
- The game features waves of enemies that approach the player, with buffs appearing randomly.
- Players can attack enemies from a distance and must avoid losing health.
- The game ends when the player's health reaches zero, at which point scores are saved locally.

## Additional Information
- The game is designed to run entirely in the browser without any server-side dependencies.
- Local storage is used to save player scores and progress.

Enjoy the game!
